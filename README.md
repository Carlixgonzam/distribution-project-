# distribution-project-

ISIS 4218 distribution assignments. One folder per hand-in.

- [documento/](documento/): shared text document on Raspberry Pi 4 with an op-based Treedoc CRDT and causal delivery, no central server.
- [adhoc/](adhoc/): multi-tenant ad hoc network, nodes of one domain find each other by mDNS and exchange their APIs.

[PROTOCOL.md](PROTOCOL.md) is the class contract our nodes follow, so all the groups edit one document.
